# Property Investment Risk Calculator

This Python script demonstrates a rental yield calculator that highlights the importance of considering potential loss scenarios in property investment. It calculates net annual yield under both optimistic and pessimistic assumptions, factoring in crucial costs like vacancy periods, maintenance, management fees, property taxes, and loan interest. The example shows how seemingly small expenses can significantly reduce profitability or even lead to a negative return.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
